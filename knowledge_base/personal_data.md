
# Personal Data Management
Document ID: KB-002
Category: Stammdaten

IMPORTANT: Fictional demonstration policy.

## 1. Address Changes

When a customer reports a change of address:

- Verify the customer reference.
- Record the requested address change.
- Check whether the submitted information is complete.
- Update the customer record only after appropriate verification.

## 2. Personal Information Corrections

For corrections to names, dates of birth or contact details:

- Identify the information requiring correction.
- Request supporting information if necessary.
- Document the requested changes.
- Forward unresolved identity issues for manual verification.

## 3. Bank Details

When customers request changes to bank details:

- Never request complete banking credentials through unsecured channels.
- Use the designated secure verification process.
- Record the request without exposing sensitive information.

## 4. Escalation

Escalate the request when identity or ownership cannot be verified.
